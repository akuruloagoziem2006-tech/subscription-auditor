# Subscription Auditor

A simple tool to help you find forgotten subscriptions, track recurring payments, and see how much you could save.

## Features
- Detect and manage recurring subscriptions
- Forgotten Money Score
- High-cost subscription highlighting
- Savings simulator ("What if I cancel these?")
- Dark mode
- Demo data for first-time users

- LocalStorage
